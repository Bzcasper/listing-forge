# Listing Forge

Digital product for estate / vintage jewelry sellers.

**Value:** Turn rough item notes into eBay-ready listing packs (title, description, tags, CSV row) in seconds.

## Product angle
- Sell as a CLI + templates pack on Gumroad / Whop
- Or run in-house to list inventory faster (Caspers Heritage / estate flips)
