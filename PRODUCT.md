**One-liner:** Paste one line of item notes → get title, description, tags, and CSV row ready to list.

## Problem

Estate / vintage jewelry sellers lose hours per week writing listings:
- Staring at rough notes ("14k rope chain, 18in, 3.2g...") and rewriting them into eBay titles, descriptions, and item specifics every time.
- Inconsistent titles = worse search ranking and fewer sales.
- Copy-paste errors in weight, purity, length, and condition create returns and bad reviews.

Listing backlog = dead inventory sitting in drawers instead of selling.

## Solution

Listing Forge is a local CLI + template pack that turns messy shorthand into a complete listing pack in seconds:

Input:
```

```

Output:
- Optimized 80-char eBay title
- Clean buyer-ready description (metal, weight, size, condition, marks)
- 10-13 search tags
- 1-click CSV row for bulk upload

No subscriptions to learn, no web app, no data leaving your machine. Works offline.
